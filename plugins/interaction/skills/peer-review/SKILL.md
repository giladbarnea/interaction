Pick the mode that matches the situation:

- You are reviewing another agent’s work → @references/peer-review-instructions.md work_to_review [...args] 
- You want another agent to review your own work → @references/self-peer-review.md work_to_review [...args]

There is no clause for an agent reviewing its own work on purpose.
